Отслеживание новых посетителей канала и вывод их в лог.
Проект призван помочь начинающим стримерам с минимальной аудиторией (0-10 зрителей) налаживать контакт со случайным зрителем зашедшим на трансляцию.

<img width="1024" height="1024" alt="Gemini_Generated_Image_534al534al534al5" src="https://github.com/user-attachments/assets/d7507133-f2cc-41b3-9777-6b3e4133cd2a" />

Профили видимых пользователей загружаются с api.ivr.fi пакетами до 50 логинов и кешируются в IndexedDB на 12 часов. При массовом JOIN профили пользователей, вытесненных из видимой ленты, не запрашиваются.

Количество ников в ленте и размер аватарки настраиваются в интерфейсе и сохраняются в браузере.
